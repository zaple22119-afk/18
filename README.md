# Birthday Adventure – bez backendu

Soubory: `index.html`, `style.css`, `app.js`, `config.js`. Žádný Firebase, žádný build.

- Datum, zastávky, kódy a dopis měníš v `config.js`.
- Dá se otevřít dvojklikem na `index.html` nebo nahrát na jakýkoliv hosting (Netlify Drop, GitHub Pages).
- Postup a fotky se ukládají do prohlížeče na jejím telefonu. Pokud data prohlížeče smaže nebo web otevře
  jinde, začne od začátku.
- Odpočet jde podle hodin v telefonu; kódy jsou v `config.js`, tedy čitelné pro každého, kdo otevře zdroj stránky.
- Test před termínem: v `config.js` dej `targetDate` do minulosti; hru vynuluješ smazáním dat webu v prohlížeči.
